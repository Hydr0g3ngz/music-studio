# Music Studio v0.1.4 — NVIDIA GPU acceleration / 显卡加速安装版

Download **Music-Studio-0.1.4-Setup-x64.exe**, close Music Studio, and install over
the previous version. Songs and lyric corrections are stored separately and retained.

下载 **Music-Studio-0.1.4-Setup-x64.exe**，关闭 Music Studio 后覆盖安装。
歌曲和修改结果独立保存，无需卸载或删除旧歌曲。

- Python, **PyTorch 2.5.1+cu121, CUDA 12.1 and cuDNN 9** are included.
- Demucs htdemucs separation, Whisper small lyrics and CREPE full melody use the
  NVIDIA GPU when **Automatic** passes the runtime check. No extra basic-model downloads.
- CUDA is checked with an actual tensor computation and Whisper compute-type support;
  an unavailable GPU is disabled with an explanatory message. CPU remains a slow fallback.
- Rhythm and harmony use librosa on CPU. Qwen and turbo remain optional source configurations.

默认“自动选择”会优先使用通过检查的 NVIDIA 显卡，人声分离、歌词识别和旋律提取均支持 GPU。
不需要另装 Python、CUDA Toolkit 或 cuDNN；需已安装兼容的 NVIDIA 显卡驱动。
节拍、和弦仍在 CPU 上运行。内置基础模型可离线使用。

Windows 10 22H2 / Windows 11 x64. RTX 4070 Laptop 8GB is the local validation target.
Other GPU families are not established by that check; AMD/Intel GPU acceleration is
not included. RTX 50-series support is not provided by this CUDA 12.1 runtime.
建议 16GB RAM，预留至少 10GB 安装空间。安装包尚未代码签名，请核对 SHA256SUMS.txt。

The small **Windows.zip is source code**, not a portable offline app.
体积较小的 Windows.zip 是源码包，不包含运行环境和模型。

Installation and actual inference evidence: [GPU validation](https://github.com/Hydr0g3ngz/music-studio/blob/main/docs/gpu-installer-validation.md).
Composition and mixing belong to the independent [Music Workbench](https://github.com/Hydr0g3ngz/music-workbench).
