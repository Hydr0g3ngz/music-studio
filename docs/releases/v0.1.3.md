# Music Studio v0.1.3 — 安装即用的歌曲分析 / Standalone song analysis

下载 **Music-Studio-0.1.3-Setup-x64.exe**，双击安装后从桌面打开 Music Studio。
无需 Python、终端、账号或 API。安装包内置 CPU 环境和基础模型，可离线分析自己的歌曲。

Download **Music-Studio-0.1.3-Setup-x64.exe**, install it, and open Music Studio.
Python, CPU inference dependencies and basic models are included. No terminal,
account, API key or extra basic-model download is needed.

- Demucs htdemucs：人声与伴奏分离 / vocal and backing separation.
- Whisper small：歌词和时间估计、改字 / timed lyrics and text correction.
- CREPE full：主旋律 MIDI / vocal melody MIDI.
- librosa：和弦与节拍信号分析 / chord and beat signal processing.
- 同步试听、跟唱、导出、删除与恢复 / synchronized playback, practice, exports and Trash.
- Independent bilingual high DPI desktop window and separate song storage.

CPU 基础版：Windows 10 22H2 / Windows 11 x64，建议 16GB RAM、4GB 安装空间。
整曲分析可能需要数分钟或更久，结果需核对。本版本没有新的准确率提升声明。
Qwen、Whisper turbo 和 GPU 为源码安装的可选配置，未包含在此安装器中。

The CPU edition is not real time. Review automatic results. Qwen, turbo and GPU
remain optional source installations. This release makes no new accuracy claim.

创作、编排、混音和 ACE-Step 属于独立的 [Music Workbench](https://github.com/Hydr0g3ngz/music-workbench)。
早期工作台预发布已从此仓库公开下载中收起，历史标签保留。
Songs are saved in `%LOCALAPPDATA%\MusicStudio\Songs` and retained on uninstall.
Existing source workspaces are untouched; see [Quick start](https://github.com/Hydr0g3ngz/music-studio/blob/main/QUICKSTART.md).

核对 / Verify **SHA256SUMS.txt**. The app installer is unsigned. The Microsoft
WebView2 prerequisite is signature checked during packaging.
