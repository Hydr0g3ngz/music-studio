# Music Studio v0.1.5 · 图标与全屏 / Icon and fullscreen

为歌曲分析提供更完整的桌面体验：统一的波形图标、深色标题栏，以及隐藏系统标题栏和菜单的全屏模式。

- **全屏**：点击右上角按钮或按 F11；按 Esc / F11 恢复原窗口，保留当前歌曲、播放位置和歌词草稿。
- **轻量升级**：已有完整 GPU 版时，下载 `Music-Studio-0.1.5-Setup-x64.exe`，关闭软件后运行。安装器只更新应用与桌面程序，保留 GPU 环境和模型。
- **首次安装**：同一安装器会自动下载约 2.20GB 的已验证 GPU 基础环境，再安装最新版应用。默认使用通过检查的 NVIDIA GPU。
- **离线安装**：将本版 Setup EXE 与 [v0.1.4](https://github.com/Hydr0g3ngz/music-studio/releases/tag/v0.1.4) 的两个 `Music-Studio-0.1.4-Setup-x64-1.bin / -2.bin` 放在同一目录，再运行本版 EXE。已有 GPU 版可直接运行本版 Application-Update EXE。

歌曲、分析结果和歌词修改保留。`Windows.zip` 是需要 Python 的源码包，不是完整便携版。
本版沿用 GPU 版的 Demucs htdemucs、Whisper small 与 CREPE full；Qwen、turbo 仍为源码安装的可选项。

## English

A unified waveform icon, dark window caption and native borderless fullscreen for song analysis.

- Use the top-right **Fullscreen** button or **F11**. **Esc / F11** restores the previous window without reloading the song or losing playback position and lyric drafts.
- Download `Music-Studio-0.1.5-Setup-x64.exe`. Close the app before upgrading. Complete GPU installations receive a small app/desktop update and keep their runtime and models.
- First installations automatically fetch the verified 2.20GB GPU base and apply the latest app update. Automatic device selection prefers a verified NVIDIA GPU.
- For a first offline installation, keep this Setup EXE beside both v0.1.4 BIN files linked above. Existing GPU installations can run this version's Application-Update EXE offline.

Songs and corrections are retained. `Windows.zip` requires Python and is source code, not a portable offline application. Models remain Demucs htdemucs, Whisper small and CREPE full; Qwen and turbo are optional source configurations.

Windows 10 22H2 / Windows 11 x64. A compatible NVIDIA driver is required for GPU use.
